## 1. 気道管理・迅速導入（A: Airway）

### 筋弛緩薬と挿管の基本姿勢
* **準備が8割**: 物品・体位・吸引・人員をすべて整えてから開始する。
* **筋弛緩薬（エスラックス）**:
  * ロクロニウム（エスラックス） $1.0¥text{ mg/kg}$ が目安。
  * リスク症例では拮抗薬**スガマデクス**を必ずベッドサイドに準備。
* **筋弛緩薬を使わない選択肢**:
  * 気道確保困難の予測、高度アシドーシス時は**意識下挿管**を検討。

### RSIの3本柱（鎮静・鎮痛・筋弛緩薬）と「無理やり1の法則」

## 2. 気管支喘息発作・呼吸不全（B: Breathing）

### 急性期吸入・点滴治療
* **吸入 $¥beta_2$ 刺激薬（今すぐ効く薬）**: 数分で効果発現。
  * プロカテロール（メプチン）0.01%: $30¥text{ }¥mu¥text{g}/0.3¥text{ mL} + ¥text{生食 } 3¥text{ mL}$
  * （代替: サルブタモール/ベネトリン0.5% $0.3¥text{ mL} + ¥text{生食 } 3¥text{ mL}$）
  * 投与頻度: 改善するまで**20分ごと・最大3回**反復吸入。
  * $¥text{SpO}_2$ 低下・会話困難時は酸素投与を併用。
* **ステロイド（あとで長く効く薬）**: 中等度以上で併用。
  * 点滴: ベタメタゾン（リンデロン）$8¥text{ mg} + ¥text{生食 } 50¥text{ mL}$（30分〜1時間かけて投与）。
  * 帰宅時処方: プレドニゾロン（プレドニン）$0.5¥text{ mg/kg/日}$ を数日間（例: $50¥text{ kg}$ なら 朝$10¥text{ mg}$ - 昼$10¥text{ mg}$ - 夕$5¥text{ mg}$）。

### 重症度判定と喘鳴の鑑別
* **中等度の目安**: 起座呼吸（横になれない）、$¥text{SpO}_2¥text{ }91¥sim95¥%$。
* **重症度サイン**: 会話が「文 $¥to$ 句 $¥to$ 単語」と短くなるほど重症。**silent chest（呼吸音消失）は最重症**。
* **喘鳴 $¥neq$ 喘息（鑑別）**:
  * アナフィラキシー（蕁麻疹・腹痛を伴う）
  * 心不全（心臓喘息）
  * COPD増悪
  * 上気道異物

## 3. ショック・循環不全（C: Circulation）

### ショックの初期介入（OMI）
* **O**: $¥text{O}_2$（酸素投与）
* **M**: Monitor（心電図・血圧・$¥text{SpO}_2$ モニター装着）
* **I**: Infusion（静脈路確保・初期輸液）

### エコーによる迅速鑑別
1. **下大静脈（IVC）拡張**:
   * 心嚢水＋右室拡張不全 $¥to$ **心タンポナーデ**（心嚢穿刺）
   * 右室拡大＋右室機能低下 $¥to$ **肺塞栓症**（血栓溶解療法）
   * lung sliding $(-)$ $¥to$ **緊張性気胸**（胸腔ドレナージ）
   * 左室壁運動異常 / 重度弁膜症 $¥to$ **心原性ショック**（ノルアドレナリン・ドブタミン等）
2. **下大静脈（IVC）虚脱**:
   * 出血・脱水 $¥to$ **循環血液量減少性ショック**（輸液・止血・輸血）
   * 敗血症・神経原性・アナフィラキシー・副腎不全 $¥to$ **血液分布異常性ショック**（輸液・ノルアドレナリン）

### 初期輸液と血管収縮薬
* **初期輸液量**: 晶質液 $30¥text{ mL/kg}$ 以上を3時間以内に投与（日本版敗血症診療ガイドライン2020）。
* **昇圧薬併用**: 輸液過負荷の害を考慮し、遅延なく併用を開始する。

### カテコラミン受容体の基礎知識
$$¥text{血圧 (BP)} = ¥text{心拍出量 (CO)} ¥times ¥text{末梢血管抵抗 (R)}$$
$$¥text{心拍出量 (CO)} = ¥text{1回拍出量 (SV)} ¥times ¥text{心拍数 (HR)}$$

* $¥alpha_1$: 血管収縮 $¥to$ 末梢血管抵抗（R）上昇 $¥to$ 昇圧
* $¥beta_1$: 心収縮力・心拍数上昇 $¥to$ 心拍出量（CO）増加 $¥to$ 昇圧
* $¥beta_2$: 血管拡張 $¥to$ 末梢血管抵抗（R）低下、心拍数増加

### カテコラミンの使い分け
* **ノルアドレナリン（Nad）**: $¥alpha_1$ 優位 ＋ $¥beta_1$。あらゆるショックの第一選択。
* **ドブタミン**: 純粋な $¥beta_1$。心収縮力低下（心原性ショック）に併用。
* **アドレナリン**: 強力な $¥alpha + ¥beta$。心停止・アナフィラキシーに。
* **ドパミン**: 用量依存性（中等量＝$¥beta$、高用量＝$¥alpha$）。

### ノルアドレナリン投与プロトコル
* **基本組成**: $3¥text{A} + ¥text{生食} = ¥text{計 } 50¥text{ mL}$。$3¥sim5¥text{ mL/h}$ で開始し、$1¥sim2¥text{ mL/h}$ 刻みで調節。
* **大急ぎの末梢持続法**:
  * $1¥text{A} + ¥text{生食} = ¥text{計 } 100¥text{ mL}$
  * シリンジで $10¥text{ mL}$ 吸い、まず $2¥sim3¥text{ mL}$ ずつ静注（$20¥sim30¥text{ }¥mu¥text{g}$ ずつ急速負荷）。
  * 残りを「3秒に1滴（$60¥text{ mL/h}$）」で点滴滴下（$50¥text{ kg}$ 換算で約 $0.2¥text{ }¥mu¥text{g/kg/分}$）。
* **末梢投与の安全性**: 肘静脈など太い静脈であれば $0.2¥text{ }¥mu¥text{g/kg/分}$ 程度まで許容可能。

### Nadで平均血圧（MAP）65 mmHg未満が維持できない場合
1. 末梢静脈路2本確保、リンゲル液 $500¥sim1,000¥text{ mL}$ ボーラス。
2. ノルアドレナリン $0.05¥text{ }¥mu¥text{g/kg/分}$ 開始、$0.01¥sim0.02¥text{ }¥mu¥text{g/kg/分}$ ずつ漸増。動脈圧ライン（A-line）留置。

   * **バソプレシン $1.8¥text{ 単位/時} ¥pm ¥text{ヒドロコルチゾン } 50¥text{ mg/6時間ごと}$**（$200¥text{ mg/日}$）を追加。

## 4. 高カリウム血症の3段階管理

治療コンセプト：**「守る $¥to$ 隠す $¥to$ 出す」**

### ① 守る（心筋膜電位の安定化）
* **グルコン酸カルシウム（カルチコール）**:
  * $1¥text{A } (10¥text{ mL})$ を3分以上かけて緩徐静注、または生食 $100¥text{ mL}$ に混注し $20¥sim30$ 分で点滴。
  * 効果不十分なら5分おきに $2¥sim3$ 回反復可。
  * ※体外へのK排出効果はない。
  * ※テント状T波単独は重篤な不整脈と相関しない。

### ② 隠す（細胞内シフト）
* **GI療法（ブドウ糖・インスリン療法）**:
  * $50¥%¥text{ブドウ糖 } 40¥text{ mL} + ¥text{速効型インスリン } 4¥sim8¥text{ U}$ 静注。
  * **安全重視の塩梅**: インスリン量とK低下作用に大きな相関はなく、最大$75¥%$で低血糖を起こすため、「$50¥%¥text{Glu } 40¥text{ mL} + ¥text{速効型 } 4¥text{ U}$（糖 $5¥text{ g}: 1¥text{ U}$）」が安全。
  * 低血糖ハイリスク群: 腎不全、糖尿病なし、体重 $< 60¥text{ kg}$、女性。

### ③ 出す（体外排出）
* **陽イオン交換樹脂製剤**:
  * ジルコニウムシクロケイ酸ナトリウム（ロケルマ） $5¥sim10¥text{ g}$ を水に懸濁して経口投与。
  * 当日〜翌日に再検フォローし、難治例は血液透析を実施。

## 5. アナフィラキシー対応

### 診断と対応
* **皮膚症状のないアナフィラキシーに注意**: アレルゲン曝露後の急速な血圧低下・気管支攣縮・喉頭症状があれば蕁麻疹がなくても診断する。
* **最優先治療**: **アドレナリン筋注**。
  * 5分おきに追加投与可能。
  * 2回筋注しても改善しない場合は持続点滴静注へ移行。
* **アドレナリン持続投与法**:
  * $1¥text{A} + ¥text{生食 } = ¥text{計 } 100¥text{ mL}$
  * 「3秒に1滴（$60¥text{ mL/h}$）」で点滴（$50¥text{ kg}$ 換算で約 $0.2¥text{ }¥mu¥text{g/kg/分}$）。
* **$¥beta$ 遮断薬内服中の難治例**: グルカゴン $1¥text{ mg}$ を緩徐に静注。
* **抗ヒスタミン薬・ステロイドの位置づけ**:
  * ポララミン $5¥text{ mg} + ¥text{生食 } 50¥text{ mL}$ 点滴（眠気に注意）。
  * 主に皮膚症状の緩和や遅発相反応予防が目的であり、**救命の主役ではない**。

## 6. ERでの降圧薬

### ニカルジピン（ペルジピン）持続静注
* **希釈法**: 原液アンプルを生食等で希釈し、トータル $50¥text{ mL}$ とする。
* **開始速度**: $2¥sim3¥text{ mL/h}$ で開始。
* **調節**: $1¥sim2¥text{ mL/h}$ の範囲で増減。
* 必要に応じて $1¥sim2¥text{ mL}$ をフラッシュ投与。

## 7. 低血糖緊急症（D: Disability）

### 初期対応
* **意識障害あり**: $50¥%¥text{ブドウ糖液 } 40¥text{ mL}$ を緩徐に静注。
* **意識障害なし**: ブドウ糖末 $10¥text{ g}$ を経口投与。
* **チアミン（ビタミンB1）補充**:
  * 栄養失調、アルコール中毒、妊婦など欠乏リスクがある場合は、ブドウ糖投与前に必ず**チアミン（ビタミンB1）**を静注する（ウェルニッケ脳症予防）。

### 補正後の確認：Whipple（ウィップル）の3徴
1. 低血糖に合致する症状がある
2. 血糖値が低い
3. 血糖補正後に症状が改善する
* ※血糖補正後も症状が改善しない場合は、脳卒中など他の病態の合併を検索する。

## 8. けいれん重積状態の段階的治療（D: Disability）
