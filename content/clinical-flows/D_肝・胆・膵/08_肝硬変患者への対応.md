# 肝硬変患者への対応
親カテゴリ: [[clinical-flows/D_肝・胆・膵/index|D章 肝・胆・膵]]

## 重症度分類：Child-Pugh 分類

| 評価項目 | 1点 | 2点 | 3点 |
| :--- | :--- | :--- | :--- |
| **肝性脳症** | なし | 軽度（I〜II度） | 高度（III〜IV度）[cite: 273] |
| **腹水** | なし | 軽度（利尿薬でコントロール可） | 中等度以上（難治性）[cite: 273] |
| **総ビリルビン (mg/dL)** | $<2.0$ | $2.0\sim3.0$ | $>3.0$[cite: 273] |
| **血清アルブミン (g/dL)**| $>3.5$ | $2.8\sim3.5$ | $<2.8$[cite: 273] |
| **PT活性値 (%) / INR** | $>70\%$ ($<1.7$) | $40\sim70\%$ ($1.7\sim2.3$) | $<40\%$ ($>2.3$)[cite: 273] |

- **Grade A (5〜6点)**: 代償期、2年生存率 90%[cite: 273]。
- **Grade B (7〜9点)**: 移行期、2年生存率 70%（肝移植適応評価開始）[cite: 273, 280]。
- **Grade C (10〜15点)**: 非代償期、2年生存率 38%[cite: 273]。

## 合併症マネジメントプロトコル

### 1. 腹水（Ascites）
- **塩分制限**: 食塩 5 g/日未満[cite: 273]。
- **利尿薬療法**: **スピロノラクトン 100 mg ＋ フロセミド 40 mg** の比率（100:40）で開始・漸増（最大 400 mg : 160 mg）[cite: 273, 274]。
- **難治性腹水**: トルバプタン（サムスカ 3.75〜7.5 mg/日）併用[cite: 274]。
- **大量腹水穿刺排液**: $>5$ L 排液時は、循環虚脱予防のため**排液1 Lあたり 20%アルブミン 8〜10 g** を点滴静注[cite: 274]。

### 2. 特発性細菌性腹膜炎 (SBP)
- **診断基準**: 腹水穿刺液の**好中球数 $\ge250\ /\mu\mathrm{L}$**[cite: 275]。
- **初期治療**: セフォタキシム（2 g 8時間毎）またはセフトリアキソン（2 g 24時間毎）を5日間投与[cite: 275]。
- **アルブミン静注**: 腎障害・死亡率低下のため、診断初日に 1.5 g/kg、第3病日に 1.0 g/kg を併用投与[cite: 275]。
- **二次予防**: 再発率70%のため、回復後はST合剤（1錠/日）またはシプロフロキサシン（400 mg/日）を長期連日内服[cite: 276]。

### 3. 食道静脈瘤
- **一次予防**: 非選択性β遮断薬（**プロプラノロール** 20〜40 mg/日、または**カルベジロール** 6.25〜12.5 mg/日：心拍数55〜60回/分目標）または 内視鏡的結紮術（EVL）[cite: 276, 277]。
- **急性出血時**: 輸血（Hb 7〜8 g/dL目標制限輸血）、オクトレオチド持続静注（50 µg/時）、セフトリアキソン予防投与（7日間）、12時間以内の緊急内視鏡的止血術（EVL/EIS）[cite: 277]。

### 4. 肝性脳症
- **誘因の除去**: 消化管出血、便秘、過剰蛋白摂取、利尿薬・脱水、感染症（SBP）、低K血症、鎮静薬[cite: 278]。
- **薬物治療**:
  - **ラクツロース**: 1日30〜60 mL 分3（軟便が1日2〜3回出るよう調節）[cite: 278]。
  - **リファキシミン（リフキシマ 400 mg 1日3回）**: 難吸収性抗菌薬による腸内アンモニア産生菌の殺菌[cite: 278, 279]。
  - **分枝鎖アミノ酸（BCAA製剤）**: アミノレバンEN等の経口投与、フィッシャー液点滴[cite: 279]。
