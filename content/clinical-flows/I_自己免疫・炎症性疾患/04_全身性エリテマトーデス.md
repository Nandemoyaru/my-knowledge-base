# 全身性エリテマトーデス (SLE)
親カテゴリ: [[clinical-flows/I_自己免疫・炎症性疾患/index|I章 自己免疫・炎症性疾患]]

## 診断基準（EULAR/ACR 2019 分類基準）

**エントリー基準: 抗核抗体 (ANA) $\ge1:80$（HEp-2細胞間接蛍光抗体法）陽性**が必須[cite: 771, 773]。
- 以下の各ドメインの最高スコアを加算し、**合計 $\ge10$ 点**でSLEと分類（各項目は他因で説明できないものに限る）[cite: 773]：

| ドメイン | 臨床・免疫項目 | スコア |
| :--- | :--- | :--- |
| **全身症状** | 原因不明の発熱（$>38.3^\circ\mathrm{C}$）[cite: 773] | 2点[cite: 773] |
| **血液** | 白血球減少（$<4000/\mu\mathrm{L}$）(3点) / 血小板減少（$<10$万）または 自己免疫性溶血性貧血 (4点)[cite: 773] | 最大4点[cite: 773] |
| **神経** | せん妄 (2点) / 精神病 (3点) / 痙攣発作 (5点)[cite: 773] | 最大5点[cite: 773] |
| **皮膚粘膜** | 口腔内潰瘍 (2点) / 脱毛症 (2点) / 亜急性皮膚ループスまたは円板状ループス (4点) / 急性皮膚ループス（蝶形紅斑）(6点)[cite: 773] | 最大6点[cite: 773] |
| **漿膜** | 胸水または心嚢液貯留 (5点) / 急性心膜炎 (6点)[cite: 773] | 最大6点[cite: 773] |
| **筋骨格** | 関節炎（2関節以上の腫脹または圧痛＋朝のこわばり）[cite: 773] | 6点[cite: 773] |
| **腎臓** | 蛋白尿 $>0.5\ \mathrm{g/day}$ (4点) / 腎生検 Class IIまたはV (8点) / **腎生検 Class IIIまたはIV (10点)**[cite: 773] | 最大10点[cite: 773] |
| **抗リン脂質抗体**| 抗カルジオリピン抗体、抗$\beta_2\mathrm{GPI}$抗体、またはループスアンチコアグラント陽性[cite: 773] | 2点[cite: 773] |
| **補体** | C3またはC4のいずれか低下 (3点) / **C3およびC4ともに低下 (4点)**[cite: 773] | 最大4点[cite: 773] |
| **特異自己抗体** | **抗dsDNA抗体陽性** または **抗Sm抗体陽性**[cite: 773] | 6点[cite: 773] |

## 治療の基本原則

1. **ヒドロキシクロロキン (HCQ: プラケニル)**:
   - 禁忌がない限り**全例に投与**（皮疹・関節炎改善、フレア抑制、血栓症予防、臓器障害蓄積抑制、生命予後改善）[cite: 773, 774]。
   - 用量：理想体重あたり $\le5.0\ \mathrm{mg/kg/day}$（最大 200〜400 mg/日）[cite: 774, 780]。※定期的な眼底・網膜毒性スクリーニングを実施[cite: 774, 780]。
2. **ステロイドの最小化**:
   - 寛解維持期の目標は **PSL $\le5.0\ \mathrm{mg/day}$**（可能なら完全離脱を目指す）[cite: 774, 775, 778]。免疫抑制薬や生物学的製剤を早期併用してステロイドを速やかに漸減する[cite: 772, 774]。

## ループス腎炎 (LN) の治療プロトコル

蛋白尿 $\ge0.5\ \mathrm{g/day}$（または尿蛋白/Cr比 $\ge0.5$）や活動性尿沈渣（赤血球円柱等）を認めたら**速やかに腎生検**を施行[cite: 777]。

- **活動性増殖性ループス腎炎 (Class III / IV $\pm$ V)**:
  - **初期寛解導入療法**:
    - メチルプレドニゾロンパルス（500〜1000 mg/日 × 3日間）→ PSL 0.5〜0.6 mg/kg/日[cite: 776, 777]
    - ＋ **ミコフェノール酸モフェチル (MMF: 2〜3 g/日)** または **低用量静注シクロホスファミド (Euro-Lupus法: 500 mg 隔週で計6回)**[cite: 776, 777]
    - ＋ 新規多剤併用：**ベリムマブ（ベンリスタ）** または **ボクロスポリン（LUPKYNIS）** の上乗せ併用[cite: 775, 776]。
- **寛解維持療法**:
  - MMF（1〜2 g/日）または アザチオプリン（1〜2 mg/kg/日）＋ 低用量ステロイド（PSL $\le5$ mg/日）＋ HCQ を最低3〜5年間継続[cite: 776, 777, 778]。
